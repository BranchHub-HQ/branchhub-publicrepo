# Session Context

You are building an MVP recorder for an automated web-app pentesting system: a headed Playwright recorder in Node.js that captures click/fill/select/navigation actions (capture final fill values on blur), records storageState, and correlates network requests to each UI action so flows can be uploaded to a Playwright execution engine for payload injection and validation. You are also exploring a Chrome extension as an alternative recorder UX that captures DOM events and network traffic and uploads structured JSON artifacts to the backend for replay and attack execution. The immediate goal is a minimal recorder CLI/extension that outputs storageState.json, flow.plan.json, and flow.net.json with reliable action→request correlation for later attack injection.
